# 💬 Chat Sync

Chat Sync is a full-stack **real-time chat application** built using the **MERN** stack (MongoDB, Express.js, React, Node.js) with **Socket.IO** for real-time bi-directional communication. It supports **private and group chats**, **file sharing** (via Multer), and a clean responsive UI styled with **TailwindCSS** and **shadcn/ui**.

## ✨ Features

- 🔒 Authentication (JWT-based)
- 💬 One-to-One Chat
- 👥 Group Chats
- 📁 File Sharing (Images, Documents)
- 🟢 Real-Time Messaging (Socket.IO)
- 🧩 Modular Code Structure
- 🔔 Online/Offline User Presence
- 📱 Mobile Responsive

---

## ⚙️ Tech Stack

### 💻 Frontend
- React.js
- TailwindCSS
- Shadcn UI
- Axios
- Context API
- Socket.IO Client

### 🛠 Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- Multer (for file upload)
- Socket.IO
- JWT for Authentication
